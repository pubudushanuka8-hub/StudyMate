## Screen Breakdown

The StudyMate application consists of two main screens.

### 1. Home Screen
- Displays study tasks and progress.
- Shows the total number of tasks and completed tasks.
- Allows users to mark tasks as completed.
- Includes a study reminder.
- Provides an option to add new tasks.

### 2. Add Task Screen
- Allows users to enter a subject name and task description.
- Allows users to save new study tasks.
- Returns to the Home Screen after adding a task.

## Running the Application

The application was developed using Expo and Visual Studio Code.

To start the application, open the VS Code terminal and run the following command:

```
npx.cmd expo start --tunnel
```

This command starts the Expo development server in tunnel mode. The application can then be opened and tested on a mobile device using Expo Go.
